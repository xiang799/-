# 陈湘 · 个人设计作品集

参考指定网站的个人主页结构，保留黑色背景：全屏作品背景与居中姓名、左侧照片简介、横向重点项目与三列作品网格。包含 11 件独立作品、全屏项目详情、独立详情页与简历下载。无第三方运行时依赖、外部字体或远程图片请求。

## 本地运行

```sh
cd /workspace/-
python3 -m http.server 8000 --bind 127.0.0.1
```

无需安装依赖或执行构建。也可直接打开 `index.html`。部署时保留根目录 HTML/CSS/JS、`projects/`、`assets/`、`WORKS.md` 的相对路径，上传至静态托管服务即可。

## 内容维护

- [WORKS.md](WORKS.md)：11 件作品的独立目录、摘要、个人参与说明与材料来源。
- `content/projects.json`：项目标题、分类、简介、段落、图片与来源数据。
- `assets/`：从用户提供的 PDF 提取的实际作品、证件照和简历；展板保留原有水印。
- `projects/*.html`：可独立访问的静态项目详情，无需 JavaScript 即可阅读。
- `tools/build_site.py`：可选内容维护工具，仅依赖 Python 标准库。修改项目数据或工具中的个人介绍后，运行 `python3 tools/build_site.py` 重新生成首页、详情和作品目录。日常浏览无须运行它。
- `styles.css`：配色与响应式布局；`script.js`：主页 / 作品 / 简历视图切换、手机导航、作品分类、全屏详情弹层和页脚年份。

个人介绍采用最新简历；旧作品集中的教育时间等信息未覆盖最新简历。项目年份、团队分工、获奖归属和实际成效仅按材料明确内容表达。药止为本科团队概念项目，页面单独列明个人参与部分。

联系区显示简历邮箱。简历 PDF 下载包含原始联系方式。研究与实习经历没有附带独立项目图，因此收录在个人介绍中，不用虚构图片生成作品卡片。

## 验证

```sh
node --check script.js
python3 tools/build_site.py
```

在浏览器中验证 11 张卡片、交互与服务（3）、工业设计（6）、视觉与展陈（2）筛选，各项目详情、图片大图、返回与上下项目导航，简历下载、邮箱链接和手机菜单。检查 320–1440px 屏幕下无横向溢出、图片正常载入、控制台无错误。

## 参考布局与交互

视觉结构参考用户指定的 https://littlexiaochao.github.io/chaoyuan.github.io/ ，独立实现页面和交互，不引入参考站的代码、个人信息、作品或素材。首屏背景取自陈湘的 City Voyager 车厢设计。

项目卡片默认增强为全屏原生 dialog，支持 Esc、关闭按钮、键盘焦点约束与返回卡片焦点、上 / 下一项目和独立页面。未开启 JavaScript、从本地文件直接打开，或详情加载失败时，保留静态页面访问。没有视频素材，因此不添加虚假的播放按钮或第三方视频。
